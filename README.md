# أسئلة تدريبية في الذكاء الاصطناعي المتمحور حول الإنسان

موقع دراسي تفاعلي يضم أسئلة الاختبارات السابقة لمقرر **CS1352 — تصميم الأنظمة الذكية المتمحورة حول الإنسان**، مرتّبة حسب فصول المقرر، ومعها حلول مفصّلة خطوة بخطوة.

## طريقة التشغيل

افتح الملف `index.html` في أي متصفح (بالنقر المزدوج عليه). لا يحتاج الموقع إلى خادم ولا إلى أي خطوة بناء. يعمل الموقع دون اتصال بالإنترنت، لكن الخطوط تُحمَّل من Google Fonts عند توفر الاتصال، وإلا تُستخدم خطوط النظام.

## المزايا

- **الصفحة الرئيسية**: اختر الفصل الذي تريد التدرّب عليه، أو «All chapters mixed» لاختبار تجريبي شامل. وتظهر الأسئلة التي خارج الشرائح الحالية في قسم مستقل بعنوان «Topics outside your slides».
- **الترتيب من الأحدث إلى الأقدم**: الأسئلة في كل فصل مرتبة حسب الاختبار، من الأحدث إلى الأقدم: الاختبار القصير الأول (صيفي 2026)، ثم النهائي، ثم النصفي (الفصل الثاني 2026)، ثم الاختباران القصيران (الفصل الثاني 2026). الأسئلة غير المحلولة تأتي في آخر الفصل.
- **سؤال واحد في كل صفحة**، مع زرَّي **Next** و**Prev** في الشريط السفلي، ومربعات ملوّنة أعلى السؤال توضح حالة كل سؤال (صحيح، خطأ، تمت مشاهدته، لم يُحل بعد)، ويمكن الضغط على أي مربع للانتقال إليه.
- **زر «⤨ Shuffle»** في كل صفحة سؤال يخلط أسئلة المجموعة الحالية. ويوجد في الصفحة الرئيسية مفتاح «Shuffle questions» لجعل الخلط هو الترتيب الافتراضي.
- **زر «Show solution»** يعرض الإجابة مظلّلة، ثم شرحًا مفصلًا خطوة بخطوة.
- **أسئلة الاختيار من متعدد** تُصحَّح فور اختيار الإجابة. أما عرض الحل قبل اختيار إجابة فيُحتسب خطأً.
- **الأسئلة المقالية والجدولية**: افتح الحل وقارنه بإجابتك، ثم اضغط «Yes, I got it» أو «No, review later».
- **زر «📌 Note» (ملاحظة للقراءة فقط)**: يبيّن مصدر السؤال في الشرائح (رقم الوحدة ورقم الشريحة وعنوان الموضوع)، والاختبار الذي جاء منه، دون الحاجة إلى فتح الحل. ورابط «open at slide» يفتح ملف الشرائح على تلك الصفحة مباشرة (إذا كان مجلد `slides/` موجودًا بجانب `index.html`). وللأسئلة غير المصنّفة تعرض الملاحظة أقرب الصفحات ذات الصلة.
- **بعد إنهاء الأسئلة** تظهر صفحة النتيجة، وفيها:
  - **«Review my mistakes»**: مراجعة الأسئلة التي أخطأت فيها فقط، مع إجابتك والحل.
  - **«Retry them»**: إعادة حل الأخطاء من جديد.
  - **«Start this set again»**: إعادة المجموعة كاملة.
  - قائمة بالأخطاء للانتقال إلى أي منها.
- **البحث** في الصفحة الرئيسية: يبحث في نصوص الأسئلة والخيارات والجداول، دون البحث في الحلول.
- **تصفية حسب نوع السؤال** (اختيار من متعدد / مقالي).
- **المظهر**: زر «Theme» للتبديل بين مظهر النظام والفاتح والداكن، ويعمل الموقع على **الجوال**.
- **لوحة المفاتيح**: `←` `→` للتنقل، `1`–`4` لاختيار الإجابة، `Enter` لعرض الحل، `N` لفتح الملاحظة.

تصميم الموقع مبني على تصميم [OS-Practice-Questions](https://github.com/S0CloseYetS0Far/OS-Practice-Questions).

تُحفظ إجاباتك في متصفحك فقط (`localStorage`)، فتبقى بعد إعادة تحميل الصفحة، لكنها لا تنتقل إلى جهاز أو متصفح آخر. ويمكن مسحها من زر «Reset my answers» في الصفحة الرئيسية.

## المحتوى

| القسم | عدد الأسئلة |
|---|---|
| الفصل 1: من تفاعل الإنسان والحاسوب إلى الذكاء واسع الانتشار | 15 |
| الفصل 2: التصميم المتمحور حول الإنسان للأنظمة الذكية | 9 |
| الفصل 3: التفاعل خارج الشاشة | 19 (منها سؤال واحد بلا حل) |
| غير مصنّفة | 8 |
| **المجموع** | **51** |

- **الأسئلة غير المحلولة**: تظهر في نهاية فصلها بعلامة «Unsolved – for me to solve»، بنصها الأصلي دون تعديل، مع ملاحظة تبيّن سبب عدم حلها. ولا تدخل في حساب الدرجة.
- **الأسئلة غير المصنّفة**: موضوعاتها غير موجودة في الفصول الحالية، وستُصنَّف عند إضافة فصول جديدة.

الأسئلة مأخوذة من: الاختبار النهائي والاختبار النصفي للفصل الدراسي الثاني 2026، واختبار قصير للفصل الصيفي 2026، واختبارَين قصيرين للفصل الدراسي الثاني 2026.

> **ملاحظة:** واجهة الموقع ونصوص الأسئلة باللغة الإنجليزية كما وردت في الاختبارات الأصلية.
>
> ملفات الشرائح (`slides/`) وأوراق الاختبارات الممسوحة ضوئيًا (`exams/`) غير مرفوعة في هذا المستودع. الموقع يعمل بدونها، لكن رابط «Slides» داخل كل فصل لن يعمل إلا إذا وُضعت الشرائح في مجلد `slides/` بجانب `index.html`.

## بنية الملفات

```
index.html            الصفحة الرئيسية، وتقتصر على تحميل الملفات التالية
assets/styles.css     التنسيق والتصميم (الوضع الفاتح والليلي، والجوال)
assets/app.js         العرض والتنقل والبحث والتصحيح وحساب الدرجات
data/questions.js     كل المحتوى: الاختبارات والفصول والأسئلة والحلول
```

لا حاجة إلى تعديل `index.html` أو مجلد `assets/` عند تغيير المحتوى، فكل المحتوى موجود في `data/questions.js`.

### لماذا `questions.js` وليس `questions.json`؟

تمنع المتصفحات تحميل ملفات `.json` المحلية عند فتح الصفحة مباشرة من الجهاز (`file://`). لذلك وُضعت البيانات داخل سطر واحد بالشكل `window.STUDY_DATA = { ... };`، وكل ما بين علامة `=` الأولى و`;` الأخيرة هو JSON صالح يمكن قراءته بأي أداة.

## صيغة البيانات (`data/questions.js`)

```js
window.STUDY_DATA = {
  "course": "...",
  "updated": "YYYY-MM-DD",
  "sources":  { "<sourceId>": { "label", "short", "order", "file", "notes" } },
  "chapters": [ { "id": "ch1", "number": 1, "title", "slides", "slideCount", "summary", "topics": [], "keyTerms": [] } ],
  "questions": [ { ... } ]
};
```

حقول كل سؤال:

| الحقل | المعنى |
|---|---|
| `id` | معرّف فريد، مثل `final-2026-q1-3` |
| `source` | مفتاح الاختبار الذي جاء منه السؤال (من `sources`) |
| `ref` و`page` و`marks` | رقم السؤال كما هو مطبوع، ورقم صفحة PDF، والدرجة |
| `chapter` | `"ch1"` أو `"ch2"` …، أو `null` للأسئلة غير المصنّفة |
| `context` | التعليمات المشتركة لمجموعة الأسئلة (اختياري) |
| `text` | نص السؤال كما ورد حرفيًا |
| `options` | خيارات الاختيار من متعدد `[{ "key": "A", "text": "..." }]` (اختياري) |
| `table` | `{ "headers": [...], "rows": [[...]] }` للأسئلة الجدولية (اختياري) |
| `notes` | ملاحظات عن مشكلات المسح الضوئي، مثل نص مقطوع (اختياري) |
| `slideRefs` | صفحات الشرائح التي جاء منها السؤال، بالصيغة `"Module 3, pp.22–24 – Tangible Interfaces"`، وتُعرض في زر «Note» |
| `relatedSlides` | للأسئلة غير المصنّفة: أقرب الصفحات ذات الصلة في الشرائح الحالية (اختياري) |
| `solution` | `{ "answer", "correctOption", "steps": [], "table" }` (للأسئلة المحلولة فقط) |
| `unsolvedReason` | سبب عدم حل سؤال مصنّف |
| `unassignedReason` | سبب عدم تصنيف السؤال ضمن الفصول الحالية |

**تُحسب حالة السؤال تلقائيًا:**
- إذا كان `chapter: null` فالسؤال غير مصنّف.
- إذا كان للسؤال فصل وحل فهو محلول.
- إذا كان للسؤال فصل بلا حل فهو يظهر تحت «غير محلولة» في نهاية فصله.

تتحدّث الأعداد في القائمة الجانبية تلقائيًا. وفي نصوص الحلول، يُعرض `**نص**` بخط عريض.

## طريقة التحديث

### عند إضافة فصل جديد (مثل `slides/Module4_HCAI.pdf`)

1. أضف عنصرًا جديدًا إلى `chapters` (المعرّف `ch4` والعنوان والموضوعات والمصطلحات).
2. راجع كل سؤال قيمة `chapter` فيه `null`: انقله إلى الفصل الجديد وأضف له `solution` و`slideRefs` (واحذف `relatedSlides`)، أو اتركه غير مصنّف.
3. حدّث قيمة `updated`.

لا حاجة إلى إعادة بناء أي شيء، وتبقى الفصول والحلول الحالية كما هي.

### عند إضافة اختبار جديد

1. أضف الاختبار إلى `sources`، مع قيمة `order` التي تحدد ترتيبه الزمني (الرقم الأكبر = الاختبار الأحدث، ويظهر أولًا).
2. أضف أسئلته إلى `questions`، مع تحديد `chapter` (أو `null`) وإضافة الحلول حيث أمكن.

### التعديل اليدوي

يمكن تعديل `data/questions.js` بأي محرر نصوص، مع الحفاظ على صحة صيغة JSON (علامات تنصيص مزدوجة، ولا فواصل زائدة في النهاية). إذا ظهرت رسالة «Data not found» أو ظهرت الصفحة فارغة، ففي الملف خطأ في الصيغة.

بعد تعديل `data/questions.js` أو `assets/app.js` أو `assets/styles.css`، غيّر رقم `?v=` في روابطها داخل `index.html` حتى لا يعرض المتصفح النسخة القديمة المحفوظة.
